What is controlling it?

A radial-basis neural policy trained by imitation, with 467 local units. It reads both joint angles and velocities and outputs elbow torque limited to ±1 N m. There is no trajectory clock or LQR fallback. Physics uses the project’s continuous Acrobot model, a fixed 50 ms control interval, and 2.5 ms integration steps. Browser arithmetic can differ slightly from the Python implementation.
