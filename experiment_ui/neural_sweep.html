Ten approaches.
The same challenge.

Three training seeds per approach. Every deployed controller is neural-only. Larger networks start with the same input–output behavior as the smaller actor; the expert policy contains a frozen learned balancing network, not LQR.

Each job gets 4,000 supervised updates followed by 1.152 million PPO transitions in 45-second episodes. The task is the final two-second approach plus continued balance. Success requires the final ten seconds balanced, with both links within 10° of upright and both link speeds below 0.5 rad/s. Bottom-start evaluation is separate. These are matched data budgets, not matched wall times.

The projection arm constrains the proposed Adam parameter step using a remembered-loss gradient; it is inspired by GEM, not a reproduction. EWC uses one empirical-Fisher penalty setting. Architecture arms use frozen-policy distillation. Results are a pilot comparison, not universal rankings of the methods.
